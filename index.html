D · Sikkerhed og data

Ansvar og dataplacering

Adgangskontrol

Medarbejderkonti med MFA og mindst mulige rettigheder. Ingen hemmelige nøgler i GitHub-repositoriet.

Kryptering

HTTPS/TLS ved adgang til websiden. Produktionsdatabase skal beskyttes med kryptering under transport og lagring.

EU/EØS og GDPR

Vælg egnede datacentre, undersøg underdatabehandlere, overførsler og databehandleraftaler. Gratis hosting garanterer ikke kravene.

D · Drift, økonomi og alternativer

Hvorfor denne løsning?

Valgt: GitHub + Render (PaaS)

Enkel deployment og mindre serveradministration. God til en statisk prototype og kan senere udvides med en backend og administreret database. Faktiske priser og regionsmuligheder skal kontrolleres før produktion.

Alternativ: Ubuntu VM + Docker (IaaS/lokalt)

Mere kontrol over operativsystem og containere, men EventRent skal selv håndtere flere opdateringer, sikkerhed, overvågning og backup. Kan bruges som lærings- og testmiljø.

Tilgængelighed

Brug overvågning og en dokumenteret fejlprocedure. Ved bookinglancering skal oppetid, kapacitet og gendannelsestid fastlægges.

Backup og genetablering

Fremtidig database kræver automatiske backups, separat opbevaring og test af gendannelse. GitHub alene er ikke backup af kunde- og ordredata.

Eksamensnote: Den fungerende leverance er denne statiske side. Arkitekturdiagrammets booking-API, database, identitetsløsning, Docker og backup er forslag — ikke funktioner, som siden påstår at have.
